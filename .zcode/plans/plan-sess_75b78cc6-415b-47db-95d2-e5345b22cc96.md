# Rencana: Hub Aplikasi Pribadi Gratis

## Rekomendasi hosting (kenapa ini)
**GitHub Pages** untuk beranda + aplikasi statis, dan **Supabase** (gratis) jika ada aplikasi yang butuh simpan data online. Alasannya:
- GitHub Pages: gratis selamanya, cukup 1 repo, tiap aplikasi tinggal jadi folder (`/kalkulator/`, `/catatan/`, dst), beranda jadi halaman utama.
- Supabase: database PostgreSQL gratis tanpa perlu bikin server/backend sendiri — dari frontend langsung bisa simpan/ambil data. Tidak ribet.
- Alternatif kalau nanti butuh: Cloudflare Pages (lebih cepat, subdomain per app) — struktur yang saya buat kompatibel dengan keduanya, jadi pindah gampang.

## Struktur yang akan dibuat di folder kerja
```
Aplikasi-aplikasi/
├── README.md              ← panduan deploy langkah-demi-langkah (bahasa Indonesia)
├── index.html             ← BERANDA: kartu-kartu link ke semua aplikasi
├── css/style.css          ← tampilan beranda (bersih, responsif, dark-mode otomatis)
├── js/apps.js             ← daftar aplikasi di 1 tempat (tambah app = edit 1 baris)
├── kalkulator/            ← contoh app statis #1 (jalan penuh)
│   └── index.html
└── catatan/               ← contoh app #2: simpan data (localStorage dulu,
    └── index.html            plus contoh koneksi Supabase yang tinggal diaktifkan)
```

## Detail
1. **Beranda (index.html)** — halaman penghubung dengan judul, grid kartu aplikasi (nama, ikon emoji, deskripsi), dan footer. Daftar kartu dibaca dari `js/apps.js` sehingga menambah aplikasi baru cukup menambah satu entri + membuat foldernya.
2. **App contoh "kalkulator"** — aplikasi statis sederhana yang berfungsi penuh, sebagai template app statis.
3. **App contoh "catatan"** — simpan catatan di localStorage (jalan langsung tanpa apa pun), disertai file komentar contoh cara pindah ke Supabase saat mau sinkron online.
4. **README.md** — cara upload ke GitHub + aktifkan GitHub Pages (push ke repo → Settings → Pages), dan catatan cara pakai Supabase untuk app yang butuh database.

Setelah selesai, Anda tinggal membuat repo GitHub, upload folder ini, dan beranda online di `https://username.github.io/namarepo/` dengan tiap app di subpath-nya.
