- Pindahkan penyembunyian banner ke awal alur: di fungsi `segarkan()`, segera setelah pengecekan login (`if (pakaiSupabase && !sesi) { tampilkanLogin(); ... }`), sembunyikan banner berdasarkan `pakaiSupabase` — yakni panggil `$("banner").classList.toggle("ok", pakaiSupabase)` sebelum `return` pada cabang login, sehingga banner hilang begitu halaman dimuat saat mode Supabase aktif, baik di layar login maupun setelah masuk.
