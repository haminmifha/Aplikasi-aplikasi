## Upgrade aplikasi Catatan menjadi aplikasi pribadi multi-perangkat (Supabase)

### Latar
Sudah ada homepage (`index.html` + `js/apps.js`, sudah punya kartu "Catatan") dan aplikasi `catatan/index.html` yang datanya di localStorage. Kita upgrade aplikasi itu agar tersimpan di Supabase (database cloud gratis) sehingga bisa diakses dari PC maupun HP, plus fitur: tambah/edit/hapus, kategori/label, pencarian, dan pin (unggulan). Tampilan mengikuti tema homepage yang sudah ada (warna, dark mode otomatis, teks Indonesia).

### Perubahan

1. **`catatan/index.html`** — tulis ulang (tetap satu file mandiri, tanpa framework):
   - **Penyimpanan**: Supabase REST API langsung dari frontend. Konstanta `SUPABASE_URL` dan `SUPABASE_KEY` di bagian atas file untuk diisi user, dengan SQL pembuatan tabel di komentar (tabel `catatan`: id, judul, isi, kategori, pinned, created_at, updated_at).
   - **Mode aman**: sebelum konfigurasi diisi, aplikasi tetap jalan memakai localStorage (data lama tetap terbaca) dan menampilkan banner kecil berisi petunjuk setup; setelah diisi, otomatis pakai Supabase.
   - **Fitur**: buat/edit catatan (judul + isi), hapus dengan konfirmasi, kolom pencarian (judul & isi), filter berdasarkan kategori, tombol pin (catatan pin tampil paling atas), label kategori bebas yang tersimpan per catatan.
   - **UI**: daftar kartu catatan, form tambah/edit, responsif untuk layar HP, link "← Beranda" ke homepage, dark mode otomatis.

2. **`js/apps.js`** — kartu Catatan sudah ada; cukup pastikan deskripsinya sesuai (bukan status "soon").

3. **`README.md`** — tambahkan bagian cara setup Supabase (buat project → jalankan SQL → salin URL & anon key → tempel di `catatan/index.html`), cara menjalankan via `node serve.js`, dan cara akses dari HP (GitHub Pages atau IP lokal).

### Verifikasi
- Jalankan `node serve.js`, buka homepage → kartu Catatan → aplikasi catatan.
- Uji di browser: buat/edit/hapus/pin catatan dalam mode localStorage, pencarian dan filter kategori berfungsi.
- Tampilan dicek dalam mode terang & gelap serta lebar layar HP.

Catatan: koneksi Supabase baru aktif penuh setelah Anda membuat akun gratis dan mengisi URL & key — aplikasi akan menampilkan petunjuknya sendiri di layar.
